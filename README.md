# JavaScript Game Project

I will be creating Tic Tac Toe as my project, which will use HTML, CSS, and JavaScript. The idea of the game will have two players competing against each other placing knots & crosses in empty squares, with the goal of getting three in a row—horizontally, vertically, or diagonally. The first player to achieve this wins; if all nine squares fill up without a winner, the game is a draw.

- [] If all cells are filled and there is no winner, display a draw message

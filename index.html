THE RULES ✨

RULE 1: Two-player game played on a grid

RULE 2: You alternate placing your mark in an empty square, aiming to get three in a row (horizontally, vertically, or diagonally)

RULE 3: Player to do so wins; if all nine squares fill up without this, the game is a draw! just hit "Rematch" to start again
